# Three Meaningful GitHub Commits

The spec asks for at least three meaningful commits. The ZIP contains the complete project, but uploading everything at once creates only one commit. To satisfy the requirement, upload/commit in these three stages:

1. **Commit 1 — Specification and data**: `SPECIFICATION.md`, `data/jobs.csv`, `data/students.csv`, `system_prompt.txt`, `.gitignore`, `.env.example`, `README.md`.
2. **Commit 2 — Working program**: `main.py`, `requirements.txt`, `outputs/` reports.
3. **Commit 3 — Testing and evidence**: `tests/`, `JUDGMENT_FRAMEWORK.md`, `COST_AND_LATENCY.md`, `AI_DECISION_JOURNAL.md`, `REFLECTION.md`, and this file.

If you already uploaded the complete folder in one commit, make two more meaningful changes/commits (for example, add tests, then add documentation) rather than claiming that one upload is three commits.
